# Guia visual · Manual S.O.S. Ansiedade

**Estilo:** limpo e profissional, editorial, combinando com a capa do livro.
**Adjetivos:** confiável, sereno, cuidadoso.

## Cores
| Uso | Cor |
|---|---|
| Texto principal | `#16262A` |
| Texto secundário | `#4E5D61` |
| Títulos / fundos escuros | `#173F43` (verde-petróleo) |
| Ícones, links, checks | `#2F6F6A` |
| Fundo suave (verde) | `#EAF1EE` |
| Seções alternadas (creme) | `#F7F4EF` |
| Fundo da página | `#FFFFFF` |
| Botões (coral) | `#D4603A`, hover `#B24E2B` |
| Destaques de texto / etiquetas | `#B24E2B` sobre `#FAE6DC` |
| Bordas | `#E7E3DC` |

Coral só em botões e pequenos destaques. O resto é branco, creme e verde-petróleo.

## Fontes
- **Títulos:** Source Serif 4, peso 600, `letter-spacing: -.015em`. Frases de destaque em itálico.
- **Texto e botões:** Inter, peso 400 (texto) e 600–700 (botões, rótulos).

## Formas
- Botões com cantos de 12px (não pílula), coral sólido, sombra discreta.
- Cards com cantos de 16px, borda fina, sem sombra (sombra leve só no hover).
- Etiquetas de seção: texto pequeno em maiúsculas, coral, com traços finos dos lados.
- Etiquetas (bônus, dias) com cantos de 6px.

## Não fazer
- Sem degradês coloridos nem cores fora da paleta.
- Sem cantos muito redondos ou formato pílula nos botões.
- Sem misturar outras fontes.
