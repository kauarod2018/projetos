# Página de vendas: Kit 365 Atividades

- `index.html`: página de vendas completa (um arquivo só, abre direto no navegador).
- `PROMPT-PRODUTO.md`: prompt detalhado para criar o produto (o kit em PDF) com IA.

## O que trocar no `index.html`
- **Cores e fontes**: no começo do arquivo, no bloco `:root` (`--azul`, `--laranja`, `--creme`...).
- **Nome e logo**: procure por `Pequenos Gênios` e `PG`.
- **Imagens**: procure por `TROQUE`. Crie uma pasta `img/` e use `<img src="img/sua-foto.jpg">`.
- **Link de compra**: procure por `SEU-LINK-DE-CHECKOUT-AQUI`.
- **Preço**: procure por `120,49`.
- **Números e depoimentos** (nota 4,8, "2.300 famílias", avaliações): troque por dados reais.
